# 宏观 DEV 固定运行与状态

周期列表和详情独立显示策略开关、执行器、最后成功采集及数据参考期。策略 enabled 仅为调度意图。执行器心跳超过 120 秒显示过期；有进程证据时核对 PID、内核启动标识和开机标识，死亡或身份不符不显示运行。历史 PID 文件只读核对，不改写既有任务事实。

最后成功采集取执行记录中的真实完成时间，要求数值持久回读明确通过；自动任务可使用明确的 availability_verified。缺少证据显示未记录。原文材料状态独立保留，数值成功不代表材料下载成功。最新参考期从本地状态读取，各序列分别展示，最大参考期不代表所有序列都更新到该期。GET 不采集、不做 DDL。

就业手动更新在数值提交后和材料处理后持久记录检查点。进程中断后以相同 request_id 重放，用原数值结果与本地持久数据严格核对，不重新请求来源、不改原开始时间。材料检查点缺失显示中断未知；数值检查点之前的未知提交仍保留 unknown，不能借新抓取冒称原任务恢复。数值已被后续修订替换而无法精确匹配时，核对拒绝成功。

DEV 使用固定提交的 git archive、独立 uv 环境、uv.lock、package-lock.json 和对应 web/dist，持续开发在原工作树进行。只在新副本完成检查和构建后切换 systemd 单元的 WorkingDirectory、PYTHONPATH 和 ExecStart；旧固定副本保留可回切。服务运行目录不原地更新。

唯一 45 日窗口状态在事务运行目录的 window.json，首次正式启动记实际 started_at 和 expires_at，重启、切版和后加资产均沿用原截止。systemd 单元每次启动通过 scripts/mdf_dev_deadline.py --state 检查；缺失、损坏、超期拒绝。独立持久 systemd timer 在绝对 UTC 截止调用 stop 服务，同时每个服务配置剩余 RuntimeMaxSec。恢复时先核对 window.json 和 timer，再启动原固定版本；不能新建窗口来规避截止。

当前实施仅可开启就业自动 worker，其他族保留正常人工入口，是否加入自动更新须按就绪程度单独装配。公网域名的敏感写继续默认拒绝。本段工程、DEV 运行和未来自然发布实证分项记录；未发生发布与已经漏采分别结算。
