# 宏观 DEV 固定运行与状态

周期列表和详情独立显示策略开关、执行器、最后成功采集及数据参考期。策略 enabled 仅为调度意图。执行器心跳超过 120 秒显示过期；有进程证据时核对 PID、内核启动标识和开机标识，死亡或身份不符不显示运行。历史 PID 文件只读核对，不改写既有任务事实。

最后成功采集取执行记录中的真实完成时间，要求数值持久回读明确通过；自动任务可使用明确的 availability_verified。缺少证据显示未记录。原文材料状态独立保留，数值成功不代表材料下载成功。最新参考期从本地状态读取，各序列分别展示，最大参考期不代表所有序列都更新到该期。状态、日历、事件和历史查询 GET 不采集、不做 DDL；普通查询允许的临时缺口补源不落库，不能把它算成已保存的采集成功。

Claims 还须按 DOL 材料独立核实初请、续请各自参考周的六条值。外层 complete、普通 readback.verified 或范围 partial 都不能单独证明本次发布成功；续请参考周通常比初请早一周，也不能据此误报漏采。未来参考周待报告确认，发布日期不充作数据周。saved_points 是保存版本数（含修订），不是新增观测键数。周期预算上限仍为 24 小时 84：闭合作业按已证实 HTTP 消耗结算；旧材料请求次数未知时保留其上限，未闭合、提交未知或无法唯一关联的预留不释放。

就业手动更新在数值提交后和材料处理后持久记录检查点。进程中断后以相同 request_id 重放，用原数值结果与本地持久数据严格核对，不重新请求来源、不改原开始时间。材料检查点缺失显示中断未知；数值检查点之前的未知提交仍保留 unknown，不能借新抓取冒称原任务恢复。数值已被后续修订替换而无法精确匹配时，核对拒绝成功。

DEV 使用固定提交的 git archive、独立 uv 环境、uv.lock、package-lock.json 和对应 web/dist，持续开发在原工作树进行。只在新副本完成检查和构建后切换 systemd 单元的 WorkingDirectory、PYTHONPATH 和 ExecStart；旧固定副本保留可回切。服务运行目录不原地更新。

唯一 45 日窗口状态在事务运行目录的 window.json，首次正式启动记实际 started_at 和 expires_at，重启、切版和后加资产均沿用原截止。systemd 单元每次启动通过 scripts/mdf_dev_deadline.py --state 检查；缺失、损坏、超期拒绝。独立持久 systemd timer 在绝对 UTC 截止调用 stop 服务，同时每个服务配置剩余 RuntimeMaxSec。恢复时先核对 window.json 和 timer，再启动原固定版本；不能新建窗口来规避截止。

当前代码支持原十族及独立金融日频 worker 的显式 DEV 装配。是否运行以实际配置、进程和心跳为准；GET、部署、轮询和 enabled 状态迁移均不自动启动其他资产。网页日常入口为单项“自动采集”：开启协调来源准入、策略与必要 worker，并实际回读；关闭只停后续自动触发，在途任务收尾。中断/未知分别说明原因，仅对当前明确操作的资产恢复。控制器只允许注册资产映射的固定单元，不接收客户端 unit、命令或路径；JOLTS 使用自己的脚本。

运行版本可不同：核对 window.json 的 web_code_commit/web_snapshot、worker_versions 中的逐资产覆盖及默认 worker 绑定，不能拿旧 code_commit 代表 Web 或所有 worker。worker 快照目录必须满足已注册的完整提交目录合同；切版前核对在途任务，保留其他资产的策略意图和运行集合。当前唯一窗口为 2026-11-04T15:47:41.580036+00:00 至 2026-12-19T15:47:41.580036+00:00；文档不授权新窗口或自动切换。

公网域名的敏感写继续默认拒绝。DEV 的 Garage 明文可信 LAN 和测试数据可能丢失是既有接受，不构成生产授权，也不授权现在清库。备份/PITR 后置讨论；正常重复、未知提交核对和任务恢复仍须成立。

## BLS 停止目标与具名恢复

CPI、PPI、就业的本地采集准入拒绝发生在 service/provider 调用之前，明确记录零次来源请求。任意未知异常仍不能按零结算：自动目标保留预留并停止，诊断保留异常分类、发生阶段和实际计数是否已知，不保留原异常文本。已知 HTTP 次数也不能证明存储提交已知；`outcome_unknown` 必须先核对原回执与本地版本，不能自动重取来替代原尝试。材料回调和连接关闭的失败独立记录，不覆盖已持久的数值结果或其 HTTP 计数。

周期页对 `auto.state=stopped` 和没有下一次尝试的停止目标显示具体期间、原因和处理路径；下一期日历、worker 在线或其他期次成功不抵销该缺项。旧状态未记录底层原因时仍如实未知，修复不能反推原始失败的真实原因。

有证据的停止目标恢复采用新的具名正常增量作业，之后通过所属 Host 的本地运维端口 `confirm_target_recovery(reference_month, request_id, evidence_locator=..., diagnostic_http=...)` 核对其持久 journal、数值回执、同一参考月全部序列和严格 available 本地版本。此端口不接受网页传来的作业回执、不发来源请求，也不排历史初始化。原 `auto` 的停止、计数和未知预留保留，独立 `recovery` 标明新作业、实际时间及原阶段；不把恢复写成原自动尝试成功或自然发布捕获。调用前把已发生的具名诊断请求计入保守的单事件上限核对，同一作业重复确认不重复扣款或写入。

## CPI/PPI 历史日历视图

CPI/PPI 的日历写路径在同一原子状态文件内保留 `calendar_publication_history`。每个版本保存当时的日历、月份映射和必要目标事实，不保存数值执行结果。`observed_at` 为完整日历视图在 MDF 形成的时刻，`available_at` 为该视图的本地记录时刻；原始材料的 `acquired_at`、`imported_at`、来源与内容定位仍独立保留。官方发布时间不充作这些时间。晚导入旧材料不能把后来才形成的视图放进更早的截止。

历史查询先按 observed/available 截止选择已记录视图，再在该视图内核对原文与月份证据时间。晚到日历须先通过截止过滤，才有资格覆盖目标证据。改期、取消和明确日历冲突按各自当时视图显示，冲突时间保持未知；不能反向污染旧截止。相同发布内容的重复刷新保留首次已记录视图，重启后从原状态回放。普通查询仍展示当前日历事实。GET 不联网、不写状态、不补日历历史、不创建采集任务。其他调用者保留已有源获取时间和 available 过滤合同。

升级旧状态不会推造已丢失的视图：首次写入仅记录当时实际可见视图，其前无保留版本的区间仍未知。GET 不自动迁移。若有此前真实保留的本地 schedule 快照和可校验原文，可在隔离副本中用 `record_publication_view` 构建 journal；使用完成快照的实际观察时间作为保守可得界限，不倒填到原文日期或猜测首次取得时间。恢复方案只合并已核实的 journal，并在受控发布前记录最新本地视图；不能用旧副本覆盖在线目标、作业或策略。原文相同不证明过去从未发生过改期或取消，因此保留证据之前及未采样的中间变更仍不能补证。本机制不提供缺失官方历史的推断，也不授权在线迁移或服务切换。

恢复的旧视图须用 `valid_through` 限定已核实的截止上界。超过上界到下一已证实版本之间返回未知，不能退回更旧版本或因后来原文相同就跨越缺证区间；首次新的受控写入开始新的持续记录区间。上线需配套 Web 读路径和 CPI/PPI 写路径，混用不记录历史的旧执行器不能保证回放。合并恢复记录前须在锁内捕获最新本地视图，保留现有目标、策略、原文及所有新记录。

## BLS 公告原文传输与编码

CPI/PPI/就业/JOLTS 的具名公告材料使用锁定的普通 `requests`，浏览器 User-Agent、Accept、Accept-Language 不含邮箱或其他私人信息。数值 API 保持原通路；日历/更正页使用下述公共文档端口，继续由各自调度与准入控制。仅允许已登记的官方归档路径，每次重定向重新校验同一原文路径，最多四次 HTTP 交换；证书验证保持开启，无自动网络重试、不读取环境代理/netrc。JOLTS 保留原共享 `CpiRequestControl(DEFAULT_REQUEST_CONTROL_PATH)`：逐交换（含重定向）预记消耗、single-flight、400/24h 和 429 冷却；本次不把这一全局额度扩到其他族。材料本身的三次预算和冷却仍独立成立，不代替共享准入。

连接与读取停顿各限 5 秒；requests 的读取超时不是总时限。受监督的独立 Python 子进程覆盖 DNS、TLS、响应头和分块正文，总期限 30 秒，终止后最多另用 1 秒回收；子进程继承调用者资源组，父进程死亡也会终止下载。JOLTS 锁由下载进程持有，异常终止会释放系统锁，未结交换保留预记次数，并由既有中断退避恢复，不释放未知消耗。压缩前和解压后均逐块检查 2 MB 上限；gzip/deflate 增量解压本身也限额，不等整篇读完才检查。

留存对象是逐字节的 HTTP 实体原文（解开 HTTP Content-Encoding，不做字符替换），原始 hash、取得时间及首次 available 不因解析、重复导入或重启而改变。解析默认严格 UTF-8/BOM。已核实的 2026-11-10 CPI 原文含六个非法 `0x9d`，仅对其固定内容 hash 的非统计分类更名段落作审计标记：还须核对具名归档、PRE 正文位置、上下文，且不能处于表格、表头或 HTML 属性。派生解析文本用可见 U+FFFD 标记，不推断原字符；`parser_input` 留下每个原字节位置、原文/派生 hash 和策略版本。其他损坏（含数值、日期、表头及未知正文）拒收，不全局替换或丢弃字节。正常 UTF-8 解析合同和 JOLTS 既有独立编码兼容不变。

原文成功、可证明统计项、连续版本绑定和共识是不同证据。仅保留原文不能补出未支持的统计项或历史首发时间。后续仅补材料须由受控既有材料采集路径执行，复用已确认数值、原目标和冷却，不重采数值或改写旧失败。本说明不授权部署、重置冷却或在线补取。

## 非 API 公共文档的读取边界

已登记的 BLS 日历/更正页、BEA 日历/PIO 公告、Census 零售日历/公告及 M3 日历/PDF、DOL 日历/PDF、联储政策 HTML、财政部 XML 和固定信用归档 CSV，使用 `public_web_transport` 的受监督普通 requests 单次交换。仅接受具名 URL 模式、固定归档提交及已支持的查询参数，证书验证开启，无邮箱、环境代理/netrc、自动重定向或网络重试。连接/读取停顿最多 5 秒，总时限沿用各调用者 10/12/15/20/30 秒预算，子进程清理最多再用 1 秒；传输前及增量解压后的大小均受原 2 MB 或 DOL 8 MiB 上限约束。原文为解开 HTTP Content-Encoding 后的精确实体字节，不做字符解码修正。HTML/ICS/PDF/XML/CSV 仍各自由现有结构/身份解析器验证，HTTP200 拒绝页不是数据。CPI 的具名编码例外不向其他文档推广。

准入继续由原来源控制持有：BLS/JOLTS 页面逐重定向计数，Census 共用票据、DOL/金融按原站点账本、额度、间隔及重试规则执行，不以新传输替代这些控制。公共文档适配器可以通过 `with_response_headers` 端口提前记录响应，确保正文超时前已收到的 429/Retry-After 只计一次。没有该端口的数值 API 仍按原调用和结算路径执行；NYFed JSON 的 URL、请求头和正文合同保持原样。子进程回收结果未知时保留预记消耗与中断标记，沿既有恢复退避核实，不据此退还未知请求或立即切换备用页面。

旧 `bls_web_transport` 的 TLS 广告 workaround 仅作为显式注入兼容端口保留，其 TLS1.3 安全断言继续测试；实际日历/更正页默认采用新 requests 端口。正常 requests 使用经过证书/主机名验证的安全 TLS 默认配置，不继续使用旧 DEFAULT 广告。FOMC 关闭通路只作静态审查，不因本修复启用。数值 API、内部 Garage/PG、条款/说明链接不机械套用页面传输。

确定性测试的 socket mock 无法跨 exec 继承，因此 CI 同时禁止未受控的公共下载子进程及主机绑定请求账本。需要材料的离线工作流须提供明确 fixture；没有材料的数值测试须明确报告材料缺失。`live_provider` 仍需显式 opt-in，真实取样原件与观察留在忽略的事务证据中。原有通过计数不能单独证明子进程未访问来源，应以具备这些防护的最终候选回归为准。
