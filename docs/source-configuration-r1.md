# 来源配置

宏观接入包包含美国 CPI、美国 PPI、美国 JOLTS、美国就业、美国零售销售、美国消费与收入、美国初请与续请失业金、美国 GDP 与增长、美国 PCE价格指数九族。来源页按本次选择标出所需来源，保留未启用能力的来源与资产关系。数值通路从当前 canonical 绑定投影；同一能力下来源、数值通路、原始机构、发布日历和备用通路均相同的关系合并展示，内部绑定不删改。不同关系分别展示，缺失时明确显示未装配。

初请与续请的当前数值提供者是 FRED，原始机构是 DOL/ETA，发布日历是 DOL 官方周报日历；CSV 备用数值通路未装配。BLS、BEA、Census 的来源关系分别展示，不将发布日历可用性当作数值来源资格。共用组件在其他包使用“能力与来源关系”标题。

FRED 与 BLS、BEA、Census 共用现有 write-only 替换、CAS 和私有不可变凭据文件。保存后 Host、查询/执行消费端与显式验证使用同一有效凭据加载路径；当前凭据引用损坏时不回退。页面不回显、恢复或自动重发已提交的 Key。冲突或提交结果未知时须重读核对；确认未提交的失败会清空密码，用户可重新输入或取消替换。停用能力保留已有凭据与历史。

四个来源的密码输入旁均提供“保存整包配置”和取消替换入口，并列出待提交的能力变更数量及凭据来源。该入口复用两个页签共用的一次原子保存，包含全部待提交的能力与凭据修改。保存进度、结果、错误及冲突/未知结果的回读入口显示在所用来源附近。取消某来源替换只丢弃对应草稿；保存不发起来源验证或采集。

`POST /api/r5/packages/{package_id}/sources/{source_id}/verify` 接受仅包含 `expected_revision` 的 JSON。只有用户显式点击才请求上游，沿用 Host 写权限、受控 Host、同源门禁、能力准入及既有跨进程共享请求控制。每次检查至多一次实际交换，不自动重试、不采集、不写业务数据库。进程内检查互斥，同配置、同有效凭据的结果在30秒内复用。各来源沿用既有传输超时上限。TDX/KD 尚未装配配置验证，页面明确说明并隐藏无法执行的验证入口。

配置存在、请求成功、认证确认、来源资格和采集准入分别表达。FRED 的具名元数据合法成功可确认本次凭据认证；BEA 的合法 GetDatasetList 结果可确认 UserID 认证。BEA 明确业务错误1表示认证拒绝，错误7表示限流并反馈到与HTTP429相同的共享冷却；未知业务错误不建立认证或配额结论。BLS 请求成功仍保留认证未知。Census 官方接口要求 API key，只有实际已保存 Key 返回通过指定数值合同的单元格时才确认认证。HTTP200须通过业务与响应合同检查，重复JSON成员视为歧义响应并拒绝；403、限流、超时、协议错误不一律归因于 Key。验证不改变来源资格、采集权限、策略或已保存数据读取。

Census 验证请求限定2025-01、美国、44X72/SM、季调且非误差数据，用于检查已保存配置能否取得指定数值。MARTS 在 get 与 predicate 重叠时会追加维度列；category_code、data_type_code、seasonally_adj、error_data 各允许一至两列且值必须一致，数值、月份与地理列仍唯一。单行完整字段集、列数、所有指定口径及正数合同均须匹配；冲突、错列、空值、多行或元数据页继续拒绝。

Census 传输层丢弃本无状态客户端不使用的全部 Set-Cookie，并按顺序合并 Vary、Cache-Control 等明确的列表元数据。重复长度、重复传输编码、长度与传输编码共存、无效长度及不支持的传输编码继续拒绝，保留正文大小上限与无重定向约束。危险协议错误保留已观察到的安全HTTP状态，不泄露响应正文或Cookie值。

验证结果只保留本次服务进程内，重启后显示尚未验证。结果通过配置版本和有效凭据的私有进程内身份关联当前环境、包及来源；检查期间配置竞争拒绝发布结果，回读发现版本或凭据变化时撤销旧成功。结果提供检查时间、请求结果、认证结论和安全原因；时间统一用 `formatBeijingTime` 标明北京时间。HTTP响应不含 Key、凭据身份、私有引用、请求URL、提供方正文或原始异常。

认证与协议依据为 [BEA 官方 API 用户指南](https://apps.bea.gov/api/_pdf/bea_web_service_api_user_guide.pdf)（2026-04-20版）、[Census 官方查询示例](https://api.census.gov/data/timeseries/eits/marts/examples.html)、[RFC9110 §5.2](https://www.rfc-editor.org/rfc/rfc9110.html#section-5.2) 和 [RFC9112 §6.3](https://www.rfc-editor.org/rfc/rfc9112.html#section-6.3)。本事务已留存有界真实来源及正常Chromium核验证据：FRED认证确认、BLS请求成功且认证未知、Census指定数值验证与认证确认。BEA成功认证投影和业务限流反馈另有确定性合同证据；历史观察不回填或改写为新的真实请求结果。
